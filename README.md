# KEIBA NOTE V5.5.0

## V5.5.0
- AI予想を「◎本命・○対抗・▲穴」の3頭方式に簡素化。
- ChatGPTから1レースまたは開催日の全レースを複数行でまとめて貼り付け可能。
- 予想データは端末に保存し、Supabaseログイン中はクラウドにも保存。
- レース結果・最終人気・最終単勝オッズの自動紐付けは次段階で実装予定。
- iPhone版でもバージョン情報をヘッダーに表示。
- JRAレース情報の自動更新処理は変更していません。
- data/jra-schedule.json は同梱していません。既存の最新データを上書きしないためです。

## 貼り付け形式
KEIBA NOTE: 20260919|中山|1|7|11|5
KEIBA NOTE: 20260919|中山|2|3|8|12

1行につき1レース。日付・競馬場・R・本命・対抗・穴を指定します。
