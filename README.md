# KEIBA NOTE V5.4.12

## V5.4.12の方針
- ブラウザは `data/jra-schedule.json` のみを読み込み、JRAへ直接アクセスしません。
- スケジュールUpdaterはJRA公式の「開催日程 各日番組表」のみを使用します。
- 未来のレース取得は必須としません。日本時間の「今日」と直近7日間を更新対象にします。
- 取得できない日があっても既存JSONを削除・空化・上書きしません。
- 1開催あたり1R～12Rを揃えた日だけ新しいデータを採用します。
- 距離・馬場の抽出に失敗しても、レース名・条件・発走時刻など収支入力に必要な情報が揃っていれば採用できます。
- GitHub Actionsは毎日10:00 JSTに実行し、手動実行も可能です。
- Supabase、ログイン、収支記録、AI予想機能は変更しません。

## V5.4.12でのParser改善
JRA公式番組表のレース番号・リンク付きレース名・開催見出しなど、HTML上の表現差に対してV5.4.11より柔軟に解析します。

## データ取得の考え方
KEIBA NOTEの第一目的は当日以前のレースを選択して収支を入力・分析できることです。そのため、未来の予定を取得できないこと自体はエラーとしません。取得できた過去・当日データは既存データへ追加し、失敗時は既存データを維持します。

JRA公式の開催日程は予定情報であり、レース番号・馬場・距離・発走時刻等は変更される場合があります。投票時はJRAの最新の出馬表を確認してください。
