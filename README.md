# KEIBA NOTE V5.4.13

## 今回の方針
レース情報自動取得を「全部取得」から「最低限を確実に取得」へ変更。

最低限必要な項目は以下の4つです。
- 日付
- 競馬場
- レース番号
- レース名

距離・芝/ダート・発走時刻・条件は補助情報です。取得できなくてもレース情報として採用します。

## 自動取得
- JRA公式「開催日程」を最優先で取得。
- GitHub ActionsからJRAが403等で拒否した場合、同じJRA公式ページをJina Reader経由でサーバー側取得するフォールバックを使用。
- HTMLだけでなく、Jinaが返すMarkdown/テキストも解析。
- 1R～12R全部そろわなくても、正しいレース名を1件以上取得できれば保存。
- 取得失敗時は既存の `data/jra-schedule.json` を上書きしない。
- 対象日は日本時間の「今日＋過去7日」。未来日程の取得は必須にしない。
- ブラウザはJRA/Jinaへ直接アクセスせず、リポジトリ内JSONだけを読む。

## GitHub Actions
`Update JRA schedule` は毎日10:00 JSTに実行。必要なら手動実行も可能。

## 既存機能
収支記録、Supabase同期、ログイン、AI予想入力などには変更を加えていません。

※JRAの開催日程は予定情報のため、直前の変更はJRA公式の出馬表等で確認してください。
