# KEIBA NOTE V5.6.1

## V5.6.1
- AI予想データと実際の購入記録を明確に分離。
- AI予想に「買い / 保留 / 見送り」を保存。
- ◎・○・▲・△・☆の5段階予想を保存。
- 予想登録時刻を保存し、後から結果を見て編集しても元の予想時刻を維持。
- 予想時点の市場スナップショット（単勝オッズ、馬体重、増減、馬場、ワイド想定オッズ）を保存。
- レース情報（レース名、条件、距離、芝/ダート、頭数、馬場）を予想データ側に保存できる構造を追加。
- JRA結果は `data/jra-results.json` の独立データとして扱い、予想レコードへ結果をコピーして保存しない。
- AI予想は日付＋競馬場＋RのレースキーでJRA結果と照合。
- 実際の購入馬券は既存の `keiba_records` のまま維持し、AI予想とは別集計。
- AI予想画面に「実購入あり/なし」と実購入の投資・払戻を表示。
- ◎〜☆の3着以内率、買い件数、見送り件数、実購入収支・回収率を基本表示。
- 既存のJRAレース日程自動更新処理は変更していない。
- `data/jra-schedule.json` はZIPに同梱しない。
- `data/jra-results.json` もZIPに同梱しない。GitHub Actionsが管理する最新データを上書きしないため。

## 旧形式との互換性
従来の貼り付け形式もそのまま使用できます。

`KEIBA NOTE: 20260919|中山|1|7|11|5`

拡張形式では、4頭目・5頭目・判定・コメントを追加できます。

`KEIBA NOTE: 20260919|中山|1|7|11|5|3|9|BUY|展開と期待値を考慮`

判定は `BUY` / `HOLD` / `SKIP`。省略時は `HOLD`。

## データ設計
- `keiba_predictions`: AIが予想した内容と、予想時点の市場・レース情報。
- `keiba_records`: ユーザーが実際に購入した馬券。
- `data/jra-results.json`: JRA結果の独立データ。

この3つをレースキー（`date-course-race`）で照合します。結果をAI予想へ書き戻さないため、予想時点データの改変を防ぎます。
