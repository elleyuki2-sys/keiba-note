# KEIBA NOTE V5.4.16

## V5.4.16 UI改善

V5.4.14をベースに、収支管理画面の使いやすさを改善しました。

### 今回の変更
- PC・スマホともに黒いヘッダー「競馬収支管理」をスクロール中も上部に固定。
- 「メニュー」をヘッダー内へ移動し、常時アクセス可能に変更。
- 「収支を記録」「収支履歴」「メニュー」を適度な間隔で配置し、誤操作を防ぎやすく調整。
- 「収支履歴」をメイン画面から小窓表示へ変更。ボタンを押したときだけ履歴を確認可能。
- 「収支カレンダー」の記録がある日をタップ/クリックすると、その日の馬券ごとの内訳と合計収支を表示。
- 「月別収支グラフ」は最大・最小値の上下に余白を設け、グラフが窮屈に見えないよう改善。
- 月別収支グラフの棒を下から伸ばす描画アニメーションを追加。

## 既存機能
- 収支記録
- 1レース複数馬券登録
- Supabase同期・ログイン
- AI予想入力・保存
- JRAレース情報自動取得
- GitHub Pages対応

## 重要
JRAレース情報自動取得、Supabase、既存の収支データ構造は今回のUI改善では変更していません。


## V5.4.16 UI refinement
- スマホ版の固定ヘッダーをさらにコンパクト化。
- 月別収支グラフは、画面外ではアニメーションせず、グラフが表示領域に入った時にアニメーション。
